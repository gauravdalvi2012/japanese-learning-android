# Japanese Learning

Android language-learning app for practicing Japanese vocabulary and pronunciation.

## Overview

Japanese Learning is an Android application designed to help users practice basic Japanese vocabulary through translations and pronunciation.

The project explores Android UI development, language-learning interactions, and text-to-speech functionality.

## Features

* Practice Japanese vocabulary
* View English and Japanese translations
* Listen to Japanese pronunciation
* Explore common words, numbers, colors, and phrases

## Tech Stack

* Java
* Android
* Text-to-Speech
